# 相机标定与单目测距

已有19张本人实拍棋盘照片、27mm边长和内参；RMS 0.5254px，补拍后径向边缘稳定性检查通过，可以进入A4真实尺测。A4已有[5组0.5–1.5m尺测比较](results/a4_2026-10-19/REPORT.md)与误差曲线，远端与角度实验待补。详见[实拍标定报告](results/display_27mm_19views_2026-10-18/REPORT.md)。

- `capture.py`：生成9×6内角点棋盘、手动启动相机采集。
- `calibrate.py`：角点检测、标定、逐图RMS、去畸变、5张/近正对/错误边长对比。
- `measure.py`：原图A4四角标注、平面解检查、solvePnP细化、实测误差图。
- `board.png`：可打印/显示棋盘，必须实际测量打印/显示后的方格边长。
- `measurements.template.json`：空清单，按[运行说明](../RUNNING.md)填入本人数据。

待补：约2～3m远距离A4照片和尺测，以及同距三角度数据。统一相机镜头、分辨率、变焦及距离参考点。未输入数据前，不生成冒充实测的结果。

理论说明：K中fx、fy是像素单位的有效焦距，cx、cy是主点坐标；当像素近似正方形、两轴缩放相近时fx/fy接近，并非无条件相等。重投影RMS衡量已知3D角点投回图像与检测2D角点之间的像素偏差，不能单独证明真实测距准确。

A4物体系原点在纸中心，四角对应210×297mm。输出`||t||`为光心到纸中心距离，`t_z`为光轴深度；卷尺参考必须一致。角点误差、纸张不平、焦距/变焦变化、标定姿态不足和尺测参考偏移均可能影响结果，实际大小必须从本人实验分析。
